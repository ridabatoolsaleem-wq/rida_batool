Flexbox made it easy to align cards and navigation links. 
I used it for row and column layouts instead of trying 
complex positioning.

Improving readability with spacing — I learned that text 
is easier to read with proper line-height and margin. 
Small spacing changes can make a big visual difference.

My beginner CSS checklist:
- Use consistent spacing values
- Keep color palette small and clean
- Test layout on smaller screens
- Avoid too many effects and animations

How I made the layout responsive — I used media queries 
to change card layout from three columns to one column 
on smaller devices. This made the content easier to read 
on mobile phones. I also reduced image height and font 
size slightly on small screens so the page feels more 
balanced and user-friendly.

Good design is not always advanced design. For beginner 
projects, simple colors, readable text, and consistent 
spacing create a professional result.
